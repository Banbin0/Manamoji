# Manamoji

**Give language somewhere to go.**

Manamoji is a Japanese learning app designed to bridge the gap between encountering new language and actually studying it.

This repository hosts official public builds and releases of Manamoji.

Manamoji uses a year-based versioning system:

- `26.1 Beta`
- `26.2`
- `26.3`
- `26.4`
- `27.1`

The first two digits represent the release year, while the second number represents the release within that year. Release numbering resets at the beginning of each calendar year.

Small hotfixes may use an additional patch number when necessary, such as `26.3.1`.

## About Manamoji

Manamoji is built around a simple idea: the language you encounter should be easy to turn into language you can actually study.

Manamoji brings dictionary lookup, vocabulary capture, flashcards, study tools, and language encountered across other media into one connected learning workflow.

Rather than replacing the tools learners already use, Manamoji is designed to make it easier to move language between discovery and study.

Learn more:

**https://manamoji.com**
