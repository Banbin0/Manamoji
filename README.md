# Manamoji

**Give language somewhere to go.**

Manamoji is a Japanese learning app designed to bridge the gap between encountering new language and actually studying it.

This repository hosts official public builds of Manamoji.

## Download Manamoji

### iPhone / iPad

The current iOS beta is available through GitHub Releases.

[Download the latest Manamoji beta](../../releases/latest)

> Manamoji is not yet available through the App Store.  
> The current iOS beta must be sideloaded onto a supported Apple device.

For installation help, visit:

**https://manamoji.com/beta**

### Android

Android beta testing is currently being organized separately.

Visit:

**https://manamoji.com/beta**

## About Manamoji

Manamoji brings dictionary lookup, vocabulary capture, flashcards, study tools, and language encountered across other media into one connected learning workflow.

Learn more:

**https://manamoji.com**

## Beta Software

Manamoji is currently in active development.

Beta builds may contain bugs, incomplete features, or behavior that changes between releases. Users should not rely on beta builds as their only copy of important study material.

Feedback from beta testers helps shape future versions of Manamoji.
